🔧 Configuración Firebase

Conecta tu Realtime Database para que el pensum se actualice en tiempo real desde la nube. Una vez configurado, podrás agregar, editar y mover materias sin tocar el código.

Ve a console.firebase.google.com y crea un proyecto
Activa Realtime Database → Crear base de datos → Modo de prueba
Copia la URL del database (ej: https://mi-proyecto-rtdb.firebaseio.com)
En Reglas, pega: { "rules": { ".read": true, ".write": true } } (solo para pruebas)
Pega la URL arriba y haz clic en Guardar URL, luego recarga la página
En el panel de Administración haz clic en 📥 Importar Pensum Base para cargar todas las materias
